# Серверное приложение

Современное веб-приложение с серверной архитектурой, построенное на Next.js 15 с TypeScript.

## 🚀 Возможности

- **REST API** - Полноценные API маршруты для работы с данными
- **Управление пользователями** - CRUD операции для пользователей
- **Система задач** - Создание, отслеживание и управление задачами
- **Почтовый чекер** - Полноценная проверка POP3, SMTP и IMAP серверов
- **Мониторинг системы** - Отслеживание состояния сервера и метрик
- **Современный UI** - Красивый интерфейс на основе Tailwind CSS и Radix UI
- **TypeScript** - Полная типизация для надежности кода

## 🏗️ Архитектура

```
├── app/
│   ├── api/           # API маршруты
│   │   ├── users/     # API для пользователей
│   │   ├── tasks/     # API для задач
│   │   └── stats/     # API для статистики
│   ├── components/    # React компоненты
│   ├── services/      # Сервисы для работы с API
│   └── page.tsx       # Главная страница
├── components/        # UI компоненты
└── services/          # Бизнес-логика
```

## 🛠️ Технологии

- **Next.js 15** - React фреймворк с серверными возможностями

## 📡 API Endpoints

### Пользователи
- `GET /api/users` - Получить всех пользователей
- `POST /api/users` - Создать нового пользователя

### Задачи
- `GET /api/tasks` - Получить все задачи (с фильтрацией)
- `POST /api/tasks` - Создать новую задачу

### Почтовые серверы
- `GET /api/mail-check` - Получить список почтовых серверов
- `POST /api/mail-check` - Проверить почтовый сервер
- `GET /api/mail-check/servers` - Получить все серверы
- `POST /api/mail-check/servers` - Добавить новый сервер
- `PUT /api/mail-check/servers` - Обновить сервер
- `DELETE /api/mail-check/servers` - Удалить сервер
- `POST /api/mail-check/advanced` - Расширенная проверка сервера
- `POST /api/mail-check/bulk` - Массовая проверка всех серверов

### Статистика
- `GET /api/stats` - Получить статистику системы

## 🚧 Разработка

### Добавление новых API маршрутов

1. Создайте файл в `app/api/`
2. Экспортируйте HTTP методы (GET, POST, PUT, DELETE)
3. Добавьте типы в `services/api.ts`
4. Создайте компоненты для отображения данных

### Добавление новых компонентов

1. Создайте файл в `components/`
2. Используйте существующие UI компоненты
3. Добавьте TypeScript интерфейсы
4. Интегрируйте с API сервисами

## 📧 Почтовый чекер

Приложение включает полноценную систему проверки почтовых серверов:

### Поддерживаемые протоколы
- **SMTP** - Протокол отправки почты (порты 25, 587, 465)
- **IMAP** - Протокол получения почты (порты 143, 993)
- **POP3** - Протокол получения почты (порты 110, 995)

### Возможности проверки
- **Базовая проверка** - Подключение и чтение баннера
- **Расширенная проверка** - Анализ возможностей и методов аутентификации
- **SSL/TLS поддержка** - Проверка защищенных соединений
- **Массовая проверка** - Одновременная проверка всех серверов
- **Мониторинг** - Отслеживание состояния и производительности

### Технические детали
- Реальные TCP/TLS соединения (без имитаций)
- Анализ ответов серверов
- Определение возможностей протоколов
- Проверка методов аутентификации
- Измерение времени отклика
